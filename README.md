## Features

# Coding-Site2LLM

> An LLM-powered assistant for coding websites, focused on **solving problems faster** and **reading code faster**.

Coding-Site2LLM connects coding websites with LLMs to reduce the friction of reading, understanding, analyzing, and solving programming problems.

## Core Functions

### 1. Fast Problem Solving & Analysis

Get coding problems into an LLM workflow quickly.

- Analyze problem statements and requirements
- Understand constraints and edge cases
- Discuss algorithms and possible approaches
- Analyze existing solutions
- Help debug and improve code
- Reduce the context-switching between coding websites and an LLM

The goal is not simply to generate code, but to make **problem analysis and solving faster**.

### 2. Fast Reading

Use an LLM to quickly understand code and other content on coding websites.

- Explain unfamiliar code
- Summarize long problem statements
- Identify important information
- Analyze existing implementations
- Extract the structure and key logic of code

The goal is to reduce the time spent manually parsing large amounts of technical content.

## Install

1. Open `chrome://extensions/`.
2. Enable **Developer mode**.
3. Drag and drop the `.crx` file onto the extensions page.
4. Pin the extension to the Chrome toolbar for quick access
